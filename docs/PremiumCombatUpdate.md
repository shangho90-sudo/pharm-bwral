# 프리미엄 로비와 전투 연출 업데이트

사용자가 제공한 프리미엄 로비 이미지를 UI 아틀라스로 사용합니다. 닉네임, 방 이름, 서버 주소는 실제 입력창이며 1:1~4:4 선택, 방 생성, 5개씩 방 조회, 페이지 이동, AI 연습, 뒤로가기가 작동합니다. 서버 조회·실패·빈 방 안내는 실시간 정보로 표시합니다.

차동호의 일반 공격은 발사 간격 1.15초→0.7초, 착탄 대기 0.65초→0.3초, 범위 반경 1.4→1.65로 변경했습니다. 전용 서버도 같은 설정과 공유 시뮬레이션을 사용합니다. 착탄 위치 조준 원을 표시합니다.

박철호의 일반 공격은 반경 3.8의 근거리 보라 충격파이며 탄환이 생기는 공격이 아닙니다. 빗나가더라도 보라색 부채꼴 충격파을 표시합니다. 스킬은 피해 감소 보호막이며 발사형 공격이 아닙니다. 보호막, 강화, 순간이동, 소환 등 각 능력의 성격에 맞는 연출을 추가했습니다.

10명의 일반 공격 소리를 Runway로 교체하고 스킬 10개·궁극기 10개 소리를 추가했습니다. 궁극기·폭발 때 섞이던 합성 기본음을 제거하고 무기 소리 볼륨을 조정했습니다. Tripo의 의료 십자·알약 효과 모델과 색상별 입자, 전기 연결선, 물결, 저격 빔, 별·다각형·독 안개 형태를 고정 풀 24개로 재사용합니다. 최대 입자 수도 제한합니다.

몸통의 회전 반응과 보행 흔들림을 추가했습니다. 피격 반응은 0.24초→0.42초, 뒤로 젖힘 12도→28도, 후방 시각 변위 0.08→0.22로 확대합니다. 캐릭터의 실제 충돌 위치는 시뮬레이션이 관리합니다. 사용하지 않는 노멀·금속 텍스처 참조를 정리하되 원본 자산은 저장소에 보존합니다.

검증: 10명×일반·스킬·궁극기 개별 30건, 각 효과 생성과 좌표, 30개 새 소리 로딩, 10개 모델의 90도 회전과 피격, 네 맵의 4:4 전체 대전, 지형 충돌, 서버 Release 빌드, 8명 WebSocket 참가·중복 선택·호스트 이전 테스트. 브라우저에서 로비 입력·조회·방 생성·스킬과 모바일 패드를 확인합니다.

온라인: 로그인 없이 닉네임으로 입장하는 서버 코드와 Docker·Render 설정은 준비되어 있습니다. 공개 서버 계정 생성이나 외부 서버 배포는 실행하지 않았습니다. GitHub Pages는 클라이언트만 호스팅하며 온라인 대전에는 별도 서버 주소가 필요합니다.

크레딧: Runway 일반 발사음 10개 각 1, 스킬 10개 각 1, 궁극기 10개 각 2, 박철호 충격파·보호막 소리 재생성 4 = 총 44. Tripo 생성 40 + FBX 변환 10 = 총 50. 작업별 ID와 비용은 generation-receipt.json에 기록합니다.
